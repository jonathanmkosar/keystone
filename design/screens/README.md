# Screens

Mockups copied from the owner's "Keystone UI" design canvas on November 24, 2026. They are reference markup, not code to ship: styles are inline with exact colour values, and they were written for a canvas viewer, so the `support.js` script tag and the `x-dc` wrapper do nothing in a plain browser. Read them for layout, spacing, components and wording. Build the interface from the tokens in `design/tokens-draft.json`.

Every name, figure and date in them is invented.
