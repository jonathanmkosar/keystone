## Plan

Branch `agents/p7-07-search-providers`, cut from `reboot`. Each adapter is one new file of `internal/tools/web` that calls `register(Kind{...})` from `init`, as P7-06 left room for; nothing in the fallback, the states or the strategies changes.

- **Documentation first.** Each provider's request and answer are read from its current public documentation on November 28, 2026, and recorded with the addresses read in a decision record: Brave's Web Search API and its rate-limiting guide, Exa's search reference and error codes, Serper (whose reference is behind a sign-in: what is public is recorded, and the rest is marked as such), and SearXNG's search API and its limiter's code.
- **One `Searcher` each**, sharing one small sender (`send.go`): the key only in the provider's own header, never in an address, an error or a log; no redirect followed, so a key header never reaches another host; the answer read up to `agents.web_search_max_bytes`, and an error answer's body read only for the provider's own error code, never shown.
  - `brave.go`: `GET /res/v1/web/search?q=&count=`, `X-Subscription-Token`; results from `web.results` (`title`, `url`, `description`, its markup taken out); what is left from `X-RateLimit-Remaining` and `X-RateLimit-Reset` on every answer (`HeaderQuota`). A 429 with the month's window at nothing is a spent quota until its reset; otherwise a rate limit for the second window's wait. 401, 403 and a 422 whose code says the token is invalid: refused. Other 400 and 422: malformed.
  - `exa.go`: `POST /search`, `x-api-key`, `{"query","numResults","contents":{"highlights":{"maxCharacters"}}}`; results from `results` (`title`, `url`, highlights, else summary, else text). 401: refused; 402: quota spent; 403: refused, unless its tag says the query itself was refused by a content policy (malformed: the search stops with Exa's words); 429: rate limit with `Retry-After`; 400: malformed; 5xx: unavailable.
  - `serper.go`: `POST /search`, `X-API-KEY`, `{"q","num"}` with `num` 10 (or 20 for more than ten, never in between, since Serper prices by tens); results from `organic` (`title`, `link`, `snippet`). 401 and 403: refused; 402, and a 400 that says the credits are spent: quota; other 400 and 422: malformed; 429: rate limit.
  - `searxng.go`: no key; `GET /search?q=&format=json`; results from `results` (`title`, `url`, `content`); 429 (its limiter): a rate limit; 403 (JSON not switched on in its `settings.yml`): unavailable with words that say so, never refused, since a provider with no key could never leave refused; no results with every engine unresponsive: unavailable, so the search moves on. Unmetered.
- **SearXNG's address.** The entry needs an endpoint, which must be this machine or the home network by decision 0051's address rule (exported from `internal/models` in a new file, nothing else there changes), or marked trusted. `Provider` gains `trusted`, which only an install entry may set, so only the admin trusts an address (a new tenant migration `20261128T160000`, and the same column added to `data/admin/search.db`). A local SearXNG is called without the environment's proxy.
- **Default endpoints** are three install settings, `web.brave_endpoint`, `web.exa_endpoint` and `web.serper_endpoint`, as Tavily's is; an entry's endpoint still wins.
- **Proof** (`go test ./internal/tools/web`, stand-ins on `httptest` on this machine only): each adapter's request (method, path, key header, body or query) and its results as the documentation shapes them; each refusal and limit moved to the right state through a real search (refused, cooling for the wait given, out until the reset given, failing after `web.fail_after`, malformed stopping the search); Brave's headers read into what is left; a SearXNG entry refused at a public address, accepted local, accepted trusted only from the install; no key in any result, error or view, even when a stand-in repeats it; a redirect not followed. `verify`'s `no keys in output` gets the four kinds in its `search providers` surface.
- **Left on the owner's gate**: the live check with his Brave, Exa and Serper keys and his SearXNG's address.
