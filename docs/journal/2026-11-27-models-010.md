## What was learned

- Ollama's decision API is published (docs.ollama.com/api/systemone): questions keyed by name, `choice`, `noul` and `score`, probabilities that sum to one, a confidence that is a measure of spread, and errors as `{"error": "..."}`. Its page says 0.35.0; the spec says 0.35.1, which is kept.
- A Go map loses the order of a choice's options, which carry meaning ("step n of m, smallest first"), so the adapter writes its JSON objects in order with a small writer of its own.
- The embedding path was the pattern to copy: a call of its own on the seam, an optional method on the provider, and an `Open...` beside `Open`. The difference is where the recording lives: embeddings record inside `internal/turn`, next to their settings; decisions record in a package that reads no setting, so `verify` can hold it to the fixed rules, and the router passes the cap and the estimate in.
- The real browser test fails under the Bash tool's sandbox on this machine (Edge stops at once) and passes from PowerShell. `verify` was run from PowerShell.
- The worktree was again cut from the Python `main`; the branch was made from `origin/reboot` before any work.
