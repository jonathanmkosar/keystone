## What was learned

- **Brave answers a bad key with 422**, not 401, by a forum post that is the only place its error body is shown. Reading 422 as malformed, as Tavily's adapter does, would have stopped every search at a provider whose key is wrong, the one case the fallback is for.
- **A per-second window could pass for the month.** `HeaderQuota` takes Brave's last window as the month; Brave's adapter reads `X-RateLimit-Policy` when it is there and takes the longest window of a day or more, so a plan reporting only a per-second window does not go out after one search.
- **A SearXNG cannot be `refused`.** It has no key, and `refused` lasts until the key changes; its 403 (JSON not switched on) is a failure a soft test can recover from.
- **Go carries custom headers across a redirect to another host.** Only `Authorization` and cookies are dropped, so `X-API-KEY` would follow; the four adapters follow no redirect.
- **Serper's reference is behind a sign-in.** Its adapter rests on its public example answer, what its clients send, and a forum thread; decision 0752 says so, and the live check confirms it.
- **The session's scratch folder is shared with the other lanes running at once**: a verify log under a common name was another agent's. Logs now carry the item's name.
