# Models 001, 2026-11-24

Item done: P3-01, the model seam's internal request and stream format.

## What was done

- A new package, `internal/seam`, with the format as plain data and functions. Standard library only.
- `Block`, one struct for the six kinds of content: text, image, file, tool call, tool result, thinking. `Message`, `Tool` and `Request` are built from it.
- `Event`, one struct for the six kinds of stream event: start, block start, block delta, block stop, stop, error. `Usage` is the token count, carried by the stop event. `Error` sorts a failed call into seven kinds.
- `Validate` functions for a block, message, request, usage, event and response. `Encode` and `Decode` functions that validate on the way out and on the way in.
- `Collector`, which folds a stream into a `Response` and keeps what arrived when a stream fails. `Events`, which turns a `Response` back into a stream.
- The doc `docs/architecture/seam.md`, a row in the overview, a line in `verify`'s list of parts, and decision 0010.

## What was learned

- One struct with a `type` field reads and writes as JSON with no hand-written decoder. An interface with a struct for each kind would have needed one in three places. The cost is that the compiler does not catch a stray field, so validation does. Recorded as decision 0010.
- Providers disagree on whether cached input is inside the input count. The format fixes one meaning: input, output, cache read and cache write do not overlap. Each adapter converts.
- A stream can open a block and send nothing in it. The collector drops such a block and keeps its own count of indexes, so the next block still lines up.
- A tool call's input arrives as pieces of JSON text that are whole only when joined. The opening event carries the id and the name, and the input is checked when the block closes.
- The worktree for this loop was cut from the Python `main`, not from `reboot`. It had no commits of its own, so its branch was moved to the local `reboot` tip, `b98b416`, before any work.

## What was verified

On Windows 11 with Go 1.26.0: `gofmt -l .` prints nothing, `go test ./...` passes, and `go run ./tools/verify` is 8 of 8. The seam tests cover 98.6% of the package's statements. Every block type and every event type goes through JSON and back unchanged. A reply with thinking, withheld thinking, text and two tool calls goes through a stream and back unchanged. Twenty out-of-order streams are each refused.
