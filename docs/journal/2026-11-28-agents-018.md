# Agents 018, 2026-11-28

Item done: P13-01, the tricked-agent drill. Instructions planted in a web search result, a web page, a fetched file, an email, a calendar event, a connector's result and its tools' descriptions, and a knowledge source are obeyed by a scripted model against the real server: 41 attempts to send mail, change events, write files, send forms, start work, change Keystone's settings, approve itself and carry sensitive content to a hosted model. Every one is refused or asks, nothing it aimed at happens, no hosted model is sent a sensitive word, and every call is in the audit log. **One attempt got through and was fixed**: a connector tool's description reached the model before any tool ran, so a tool set to `always` ran on it (decision 0760).

The item was built in its own worktree, on `agents/p13-01-tricked-agent`, cut from `reboot` at 165ada6.

## What was done

- **The drill** (`internal/trickdrill`, new): `Run` makes a throwaway folder with one invented person, a local and a hosted model, and starts the real server (`app.Open`) with stand-ins on this machine: the drill's model on the seam for both models (`model.go`), a search provider, the fake browser, the stand-in Google with the plant in its `Echo`, a test MCP server of three tools, and a stand-in for Keystone's own address (`plants.go`). The person is set up through the API with every changing tool set to `always` (`fill.go`); thirteen cases play the plants (`cases.go`); each turn's cards are declined through the person's route, and each obeying call is judged from its approval row and its two audit entries (`play.go`); the last checks look at every stand-in, the hosted model's requests, the search queries, the person's policies and settings, and the model calls' entries (`last.go`).
- **The model obeys only what reached it**: an obeying step is played only when its planted words are in the request (decision 0761). A plant that never arrived fails the drill.
- **The fix** (`internal/connectors/offer.go`, one `if` added at the top of `Pool.line`): a tool of a connector whose results are outside content is offered by its name and its connector's name until `load_tools`, whose result marks the chat. Gmail and Calendar, and a connector the person marked as not outside, keep their lines. Its test is `TestAnOutsideConnectorsWordsAreNotOfferedBeforeLoadTools` in a new file.
- The standing check `tricked-agent drill` (`tools/verify/trickdrill.go`, one line in `checks`); `tricked-agent-drill.md`; decisions 0760 to 0763; a row and four decisions in `overview.md`; a line in `connectors.md`.

## What was learned

- **Words can reach a model without a tool running.** The outside mark is set by a tool's result. A connector's tool descriptions, offered in every call, were outside words that no result carried, so nothing marked the chat. The drill found it on its first run; nothing else got through.
- **A new space in the built-in store is normal unless labelled.** `ensureSpace` makes it so; the drill's first try at a held chat was not held until the space was labelled sensitive. Only "no row" reads as sensitive.
- **A sub-agent of a held chat whose task names a hosted model ends without a call**, and its parent is told it did not finish; the hosted model is sent nothing. A sub-agent of a chat that read outside content starts marked, so its own `always` tools ask.
- **`read_chat` of a held chat by a local model holds the reading chat**, so a plant that has the model read sensitive words and then fetch them out is stopped at the fetch.
- `web_fetch` and `browser_open` only read, so they run after outside content; an address can carry a chat's non-sensitive words to a site (decision 0763, an owner question).

## Questions for the owner

- **Should a web fetch or a browser page ask, after outside content, when its address carries words the turn did not see from the person or in a result?** As built, no: reading is free, and a held chat cannot fetch at all, so nothing sensitive can leave this way (decision 0763). Recommended: yes, for an address with a query string or path the turn did not see. Assumed meanwhile: no change.
- **Is offering an outside connector's tools by name alone, until `load_tools`, acceptable?** It costs a `load_tools` call where a name is unclear (decision 0760). Recommended: keep it. Assumed meanwhile: kept.
