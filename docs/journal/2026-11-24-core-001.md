## What was done

The repo layout from the plan, a Go module with no outside dependencies, the settings registry, and the first three commands of the binary. `keystone settings` prints 3 settings from 2 lane files.

## What was learned

- A yes or no for "may a tenant override this" does not fit the spend cap, which the admin sets for each person. The registry records a scope with three values instead (decision 0001).
- Settings are one file per lane, as PARALLEL.md asks. The registry refuses a file whose name and lane disagree, so a lane cannot write into another lane's file by accident.
