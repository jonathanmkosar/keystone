# Interface 011, 2026-11-27

Not a plan item: a fix the owner asked for from his phone. "For the phone, top menu is squeezed and can't see icons. Make the bottom chat box and options less crowded; use this chat's picture as the example to move to." His first picture showed Keystone's chat at about 390 pixels: the title cut short, the Hand off button and the project chip jammed together beside Share so neither icon read, a dashed "Attach a chat" pill under the reply, and seven controls in the composer's row. His second showed another app's composer: a roomy box, a round `+` and a model chip on the left, the microphone and a round send button on the right, and everything else behind the `+`.

Built in its own worktree, on the branch `interface/phone-header-and-composer`, cut from `reboot` at 8419a3f.

## What was done

- **The composer on a phone** (760 pixels and under, where the sidebar is already a drawer): the box has the room and is 16 pixels; one row under it holds a round `+`, the model picker as a chip with the model's short name, the round microphone and the round copper send button. The `+` opens a sheet from the foot of what can be seen, with a row for each of files or photos, attach a chat, Research, connectors and style, each with its icon, its name and its state ("1 ready", "2 attached", "off", "1 of 2 on", "Concise"). A row's own picker opens in the sheet while the others step aside; Escape, a tap outside and a choice close it.
- **The header on a phone**: the sidebar button, the title with the room and a clean ellipsis, and one `...` button that opens a sheet with Share, Hand off, the project, "Continued from" and "Continued in". The project chip, which was the second of the two icons that overlapped, moved there too. While the chat is renamed, the box takes the `...` button's room.
- **The chips over the composer** stay, compact, with 44-pixel targets inside 32-pixel chips; the dashed pill is gone on a phone, and with no chip nothing is drawn there.
- **No box takes the focus by itself on a phone**: the composer used to take it whenever a chat opened.
- **How**: `PhoneSheet.tsx` (the sheet, a context, `SheetRow`, `useNarrow`, `mayTakeFocus`), `phone-sheet.css`, and `composerSheet.ts` for the words of each state and the model's short name. Each control draws its own row when it finds itself in a sheet, so every picker, call and state is the control's own (decision 0590). `AttachedChats.tsx` now shares one picker between the pill and the row.
- **Desktop** is unchanged: the same row in the same order, the same header, the box still takes the focus.
- The write-up: a section in `web.md`, "The composer and header on a phone"; decision 0590 with its row in `overview.md`.

## What was learned

- **The overlap was the project chip, not two handoff icons.** At phone width `ChatProjectChip` was its icon alone and sat in the header's left half; the title's `min-width: 0` let the chip slide under the Hand off button. Collapsing only Share and Hand off would have left it there.
- **There is no web search switch to move.** The brief named one, but the search icon in the row is Research; web search is a tool the model uses, with no per-chat switch in the composer or the API. So the sheet has Research and no web search row.
- **A sheet inside the composer's form would send the message** on Enter in the attach picker's box. Drawing the sheet into the body with a portal fixed that and kept the controls' React context.
- **`text-overflow` does nothing on a flex box**: the chip title made a flex box for its 44-pixel height lost its ellipsis. A block with a 44-pixel line height keeps both.
- **Specificity, not order**: the phone rules live in one new stylesheet whose place in the built file depends on import order, so every rule that overrides another is written one class stronger (`form.composer`, `.composer-row.is-phone .icon-button.dictation-button`) rather than relying on coming later.
- **A sheet's "first row" must skip the file picker's hidden box**, which matched `input:not(:disabled)` and took the focus on the first try.
